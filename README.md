**Power BI Dashboard – UN Sustainable Development Goals Analysis**

Project Overview
This project explores the relationship between **education, employment, and economic growth** using data from the **UN Sustainable Development Goals (SDGs)**.

The dashboard focuses on:
* SDG 4 – Quality Education
* SDG 8 – Decent Work and Economic Growth

The goal is to analyse how improvements in education impact employment levels and economic performance.

Objectives:
* Analyse the link between **education completion rates**, **unemployment**, and **GDP growth**
* Identify trends across selected countries
* Provide insights for researchers and policymakers

Indicators Used:
* Education Completion Rate (SDG 4.1.2)
* Unemployment Rate (SDG 8.5.2)
* GDP Growth per Capita (SDG 8.1.1)

These indicators were selected because they collectively show how education influences economic and employment outcomes.

Countries Analysed:
* Brazil
* Colombia
* Peru
* Selected countries share:
  * Similar economic challenges
  * Same geographical region
  * Emerging economy characteristics 

**Dashboard Features**

Key Sections -
1. **Top Section:**
   * Title and KPI indicators

2. **Middle Section:**
   * Combo charts showing trends over time

3. **Bottom Section:**
   * Scatter plot to analyse relationships
   * Slicer for interactivity

Design & Visualisation Choices:
* Removed unnecessary axis labels and gridlines for clarity
* Used a **single legend** for consistency
* Focused on relationships rather than exact values
* Improved data-ink ratio for cleaner visuals 

Accessibility Features:
* Colour-blind friendly palette (Okabe-Ito scheme)
* Different shapes used for countries
* Enhanced marker visibility with borders
* Accessibility toggle for better usability 

Tools Used:
* Microsoft Power BI
* Data Visualisation Techniques
* Dashboard Design Principles

Files in this Repository:
* `Dashboard.pbix` – Power BI dashboard file

Key Insights:
* Education completion rates show a strong relationship with employment levels
* Countries with higher education completion tend to have better economic outcomes
* Visual analysis highlights the interconnection between SDG goals

**Conclusion**

This dashboard demonstrates how data visualisation can be used to:
* Communicate complex relationships clearly
* Support data-driven decision-making
* Highlight global development challenges
